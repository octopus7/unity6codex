# 3구도 구현 기록
기준 커밋: 78d3586 (변경 전 시안). 이번 구현 변경은 검토 가능한 미커밋 상태로 유지.

## 변경
- 기존 앞/뒤 원화 보존. 내장 image_gen으로 중간 오른쪽 측면 몸통·골반 2개 추가.
- atlas_side_source.png: 생성 원본. atlas_side_rgba.png / parts/side: 추출 결과.
- 몸통/골반은 앞→측면→뒤→측면. 측면 구간은 |cos(2π phase)|≤0.5.
- 몸통 전환은 골반보다 주기의 0.025(30ms) 앞선다. 면 선택과 어깨 연결점은 rig.json에 명시.
- 측면 몸통 폭 82, 높이 132 / 골반 폭 92, 높이 82. 높이와 피벗 체계를 유지하고 측면 폭을 줄였다.
- 프리뷰에 기존 2구도 비교, 측면 고정, 활/화살통 숨김 추가. 망토도 별도로 숨겨 신체 검사 가능.
- 4개 키 이미지, 비교 시트, GIF 갱신. body_surface_strip.png는 장비 없는 4개 포즈 비교.

## 검증과 한계
- verify_rig.py: 120샘플의 면 순서, 몸통/골반 front↔rear 직접 전환 없음, 이미지 참조, 부모 계층, 좌우 정체성, 부착 오차 검사.
- JS 구문 검사 통과. 앞선 브라우저 로컬 URL 보안 차단 때문에 실제 UI 조작 검증은 하지 않았다.
- 생성된 측면 원화를 직접 확인했으나 골반은 순수 측면보다 앞면이 더 보인다. 원화 정합은 완전하지 않다.
- 중간 측면이 들어가도 이산 이미지 교체 자체의 튐은 남는다. 어깨 연결점도 면에 따라 바뀌므로 전환 순간 위치 변화가 남는다.
- 새 몸통은 목/카라와 어깨 형태 차이가 있다. 어깨 소켓에 맞춰 팔 위치를 보정했으나 최종 미술 품질로 판정하지 않는다.
- 기존 무릎 외곽선, 의상 원근 불일치, 활 겹침, 접지 경계 속도 문제는 이번 범위에서 해결하지 않았다.
- 2구도 비교는 원래 원화 선택 방식 비교이며, 화면 전체의 정확한 과거 상태는 기준 커밋 78d3586에 보존된다.
- 원화 생성은 내장 image_gen, 파츠 추출과 보행은 코드. 프롬프트는 generation_side_prompt.txt에 보존.
